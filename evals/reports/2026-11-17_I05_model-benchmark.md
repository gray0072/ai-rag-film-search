# I05 model benchmark — 2026-11-17

Small benchmark to choose the default chat and embedding models (I05). Produced with
[tools/ai-playground](../../tools/ai-playground/README.md) (`bench-chat`, `bench-embed`); the per-model reports below are
its raw output.

**Hardware:** laptop, NVIDIA RTX 4070 Laptop GPU (8 GB VRAM), 63 GB RAM, on AC power (on battery the GPU throttles and
local calls time out). LM Studio local server, models loaded with default settings (context 8192, parallel 4).

**Scope (set by the owner):** local models of the latest generation, ≤ 20 GB on disk and ≤ 20B parameters (Gemma 3 and
Qwen 3.5 family excluded); cloud models through OpenRouter with output price ≤ $0.50 per 1M tokens, with tools and
structured output support.

## Method

Chat (`bench-chat`, temperature 0 for the scored parts, max 2048 output tokens):

- **Tool calls (10 prompts, en/ru/sv):** five fake store tools (`search_movies`, `get_movie_details`, `view_cart`,
  `add_to_cart`, `remove_from_cart`, schemas generated by `AIFunctionFactory`). A case passes when the model makes exactly
  the expected call with the expected arguments (e.g. "Jag vill se en skräckfilm från 2010-talet" →
  `search_movies(yearFrom=2010, yearTo=2019)`), or no call for a greeting.
- **Parallel calls (not scored):** "Add movies 3 and 4 to my cart" → number of `add_to_cart` calls in one response.
- **JSON (10 prompts):** `GetResponseAsync<SearchIntent>` with a JSON Schema `response_format`. *Valid* = the answer
  deserializes; *correct* = genre, years, max price and language match. Language and genres are enums in the schema.
- **Language and speed:** "recommend one movie for a cozy evening" in en/ru/sv, streamed. Tokens/s = output tokens
  (including hidden reasoning) / time from the first chunk; *first text* = time until the first visible token.

Embeddings (`bench-embed`): 10 short English overviews (document prefix) × 10 plot-description queries per language
(query prefix) → top-1 and MRR; plus translation pairs of the same query (en ↔ ru, en ↔ sv).

## Findings

1. **Thinking costs a lot and buys nothing here.** Gemma 4, gpt-oss and others think before answering when
   `reasoning_effort` is not set (LM Studio streams it as `reasoning_content`, which Microsoft.Extensions.AI does not
   show). Gemma 4 E4B with `Medium`: same tool score, JSON 8/10 (two server errors), an empty Swedish answer, first text
   after 20–29 s, the benchmark 6.6× slower (429 s vs 65 s). With `None`: 10/10 and 10/10, first text in 0.1–0.2 s.
   → New profile setting `ReasoningEffort`, `None` for the defaults.
2. **Not every model obeys `reasoning_effort: none`.** `ministral-3-14b-reasoning` still thinks (first text 26–58 s);
   OpenRouter's `z-ai/glm-5.3-flash` rejects it ("Reasoning is mandatory") and was run with `Low`.
3. **Schema enums beat descriptions.** In the first run language and genres were free strings with descriptions
   ("en, ru or sv", "in English"); Gemma 4 E4B returned `"Russian"` and Russian genre names: 0/10 correct. With enums in
   the schema LM Studio constrains generation: 10/10. Rule added to spec 06 §1.
4. **Small models invent facts.** Gemma 4 E2B recommended "Кошмар перед Рождеством (Cinderella)" and a non-existent
   Swedish title; Nemotron 3 Nano 4B a made-up plot of "Cats"; gpt-oss-20b a wrong Russian title for The Grand Budapest
   Hotel and an invented Swedish film. This confirms the rule that movie facts come only from the database (spec 06 §5).
5. **Parallel tool calls:** Gemma 4 (all sizes), Nemotron, Ministral, Haiku, DeepSeek, GPT-6 Luna and GLM return two
   `add_to_cart` calls in one response; gpt-oss-20b and Qwen 3.8 Flash return one. The agent loop (I12) must handle both.
6. **Embeddings:** EmbeddingGemma puts English, Russian and Swedish in one space (translations 0.66–0.84 cosine vs
   ~0.18 for unrelated text). Nomic v1.5 is English-only (Russian queries: 2/10). Task prefixes do not change the
   ranking here but double the gap between related and unrelated texts (0.19 vs 0.33 unrelated cosine), which matters
   for score thresholds and hybrid fusion. Swedish misses: "en kupp inne i drömmar" (Inception) and "leksaker som blir
   levande" (Toy Story); the Swedish query side is the weakest, measure again on the real catalog in I08.

## Decisions

| Profile | Model | Why |
|---|---|---|
| `local` chat | `google/gemma-4-e4b`, `ReasoningEffort: None` | 10/10 tools, 10/10 JSON, good ru/sv, ~48 tokens/s, fits fully in 8 GB VRAM. `gemma-4-12b-qat` scores the same but is 2.3× slower: the choice when quality matters more than latency. |
| `openrouter` chat | `deepseek/deepseek-v4.1-flash-1017`, `ReasoningEffort: None` | 10/10 tools, 10/10 JSON, fastest run (23 s), lowest input price ($0.036/M); `openai/gpt-6-luna` is equally accurate and costs the same per run. A dated model id keeps results reproducible. |
| `local` embeddings | `text-embedding-embeddinggemma-300m`, 768 dimensions, query prefix `task: search result \| query: `, document prefix `title: none \| text: ` | Only multilingual candidate available locally; strong cross-lingual retrieval. |

Total OpenRouter spend of the benchmark: about $0.01.
